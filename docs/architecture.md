# KnowledgeOps AI Architecture

## Overview

KnowledgeOps AI is an enterprise knowledge management and
Retrieval-Augmented Generation platform.

## High-Level Flow

User
→ Next.js
→ FastAPI
→ Authentication / Authorization
→ Retrieval
→ LangGraph
→ LLM
→ Grounded Response
→ Frontend

## Major Components

### Frontend

Next.js + React + TypeScript

### Backend

FastAPI

### Database

PostgreSQL

### Cache

Redis

### Vector Store

ChromaDB

### Embeddings

Sentence Transformers

### Agent Orchestration

LangGraph

### LLM Providers

Groq and Ollama

### Deployment

Docker + Docker Compose
